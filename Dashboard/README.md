# Source Data

The source workbook for this project is:

`marketing_analytics_dataset.xlsx`

It contains one worksheet, `Sheet1`, with 100 observations and 13 fields covering marketing delivery, engagement, conversion, spend, revenue, and row-level performance ratios.

The workbook is kept in its original analytical role as the source-data reference for the PBIX. See `../docs/data_dictionary.md` and `../docs/data_quality.md` before extending or transforming the dataset.

## Provenance

The uploaded source file was named **Marketing_Analytics_Dataset_by_Slidescope(1).xlsx**. The repository uses a cleaner filename but preserves the supplied workbook contents.

Redistribution or commercial reuse of the underlying dataset should be checked against the dataset provider's terms before reuse outside the project context.
